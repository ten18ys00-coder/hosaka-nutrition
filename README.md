# HOSAKA Nutrition

ほさか整骨院の院内スタッフ用 栄養指導システム。

- 公開ページ：`docs/` フォルダ（GitHub Pages）
- データ：Supabase（東京リージョン、姿勢アプリと同じプロジェクト内の専用テーブル `nutri_docs`）。
  行単位のアクセス制御（RLS）で、ほさか整骨院のアカウントだけが読み書きできます。
- ログイン：院のパスコード（姿勢アプリと共通）。一度ログインした端末は記憶します。
- このリポジトリに患者データは入っていません（入っているのはアプリ本体と架空の見本データのみ）。

## スマホへの入れ方
- iPhone：Safariで公開ページを開き、共有ボタン →「ホーム画面に追加」
- Android：Chromeで開き、右上のメニュー →「ホーム画面に追加」（または「アプリをインストール」）

## 開発
```
npm install
npm run build:web        # docs/ に公開用ファイルを作成
npm run build:artifact   # claude.ai版（dist/）
```
栄養計算は「日本人の食事摂取基準（2025年版）」（厚生労働省告示）に基づく決定論的な計算です。
初期の食品データは日本食品標準成分表（八訂）を参考にした試作値で、公式値と未照合です。
